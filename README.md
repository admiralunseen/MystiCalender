# MystiCalendar ✦

MystiCalendar is a circular / spiral calendar prototype for consciously inhabiting time.

## Core principles
- NOW is the centre.
- Day = spiral; Week = circle; Month = lunar wheel; Year = Q1–Q4 great wheel.
- Lunar phase is automatic from event time.
- Global season is Q1/Q2/Q3/Q4.
- Intention, Energy and Activation are optional.
- Energy can use intelligent defaults, customization, or AI assistance.
- Activation can be user-written or AI-assisted with example `I AM...` affirmations.
- `Media` is renamed **Resources**.
- Users enter name + archetype, get an AI example calendar, then modify it.
- Events open into Experience Portals rather than appointment cards.

Open `public/demo/index.html` for the dependency-free interactive prototype.
